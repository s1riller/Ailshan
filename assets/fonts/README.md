# Шрифты для серверного рендера

`CormorantGaramond-Medium.ttf` — Cormorant Garamond 500, SIL Open Font License 1.1
(см. `OFL.txt`), взят с Google Fonts. Используется только в `lib/og.tsx` для
OG-картинок: Satori не умеет системные шрифты и woff2. Шрифты интерфейса
подключаются через `next/font` в `app/layout.tsx` и сюда не относятся.
